# Oros Map — help

Oros Map is a free map of Oros for **Far Cry Primal** (PC) that reads your save file and shows what
you have done and what is left. It works offline and never changes your save.

- [Installation](Installation) — download, unzip, start
- [Using the map](Using-the-map) — filters, progress, missions, skills, fog of war
- [Troubleshooting](Troubleshooting) — save not found, Windows warning, other problems
- [Privacy](Privacy) — what the app reads and sends
